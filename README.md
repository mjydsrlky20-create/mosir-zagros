# موسیر زاگرس | Mosir Zagros

وب‌سایت معرفی و دریافت درخواست خرید عمده موسیر خشک پلاک صادراتی.

## وضعیت شاخه‌ها و انتشار

- شاخه `zagros-ai-development` شاخه توسعه و آزمایش است؛ تغییرات آن هنوز برای انتشار عمومی تأیید نشده‌اند.
- تنظیمات GitHub Pages را از روی این فایل نمی‌توان تشخیص داد؛ شاخه منتشرشده باید مستقیماً در **Settings → Pages** بررسی شود.
- تا پایان آزمایش فرم و تأیید مالک سایت، شاخه GitHub Pages را تغییر ندهید.
- انتشار با GitHub Pages انجام می‌شود و نیازی به Cloudflare نیست.

## امکانات فعلی سایت

- صفحه فارسی و انگلیسی
- معرفی فروش عمده و تأمین متناسب با سفارش
- قیمت پس از استعلام
- فرم فعلی، پیام استعلام را در واتساپ آماده می‌کند و هنوز درخواست‌ها را در بانک اطلاعاتی ذخیره نمی‌کند.
- فایل‌های `robots.txt` و `sitemap.xml`

## بانک اطلاعاتی درخواست‌ها

کد اولیه اتصال رایگان به Google Sheets در پوشه `backend/` آماده شده است:

- `backend/Code.gs`: اسکریپت ثبت درخواست در Google Sheets
- `backend/SETUP.md`: راهنمای ساخت صفحه‌گسترده و انتشار Apps Script

این اتصال هنوز فعال نیست. برای فعال‌سازی، مالک حساب باید Google Sheet و Apps Script را در حساب خودش بسازد و نشانی Web App را به‌صورت خصوصی ارائه کند. تا آن زمان فرم سایت فقط از مسیر واتساپ کار می‌کند.

## تصاویر محصول

تصاویر واقعی باید در پوشه `images/` قرار گیرند و نام فایل‌ها با مسیرهای استفاده‌شده در `index.html` تطبیق داده شوند. تا آن زمان جایگاه تصویر جایگزین نمایش داده می‌شود.

## کنترل‌های تجاری

قیمت قطعی، تأیید موجودی، تعهد تأمین، قبول سفارش، قرارداد و دریافت/انتقال وجه به تأیید مستقیم مالک کسب‌وکار نیاز دارند.
