# موسیر زاگرس | Mosir Zagros

وب‌سایت معرفی و دریافت درخواست خرید عمده موسیر خشک پلاک صادراتی.

## انتشار با GitHub Pages (بدون Cloudflare)

1. در مخزن GitHub وارد **Settings → Pages** شوید.
2. در بخش **Build and deployment**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه `version-5-improvements` و پوشه `/(root)` را انتخاب و **Save** کنید.
4. پس از پایان انتشار، نشانی زیر در دسترس خواهد بود:
   https://mjydsrlky20-create.github.io/mosir-zagros/

## امکانات و نکات

- صفحه فارسی و انگلیسی
- فرم استعلام که پیام را در واتساپ باز می‌کند؛ اطلاعات فرم در سرور ذخیره نمی‌شود.
- اطلاعات قیمت به‌صورت «پس از استعلام»
- فایل‌های `robots.txt` و `sitemap.xml`
- تصاویر واقعی محصول باید در پوشه `images/` قرار گیرند؛ تصاویر جایگزین فعلی صرفاً حالت نبود فایل را پوشش می‌دهند.

## انتشار و به‌روزرسانی

هر تغییر در شاخه انتخاب‌شده پس از ثبت در GitHub، توسط GitHub Pages منتشر می‌شود. برای دامنه اختصاصی، نشانی canonical و sitemap باید پس از تعیین دامنه به‌روزرسانی شوند.
